# 03 気象と時期

## この章で読むこと

気象（気温、降水、霜、風、日照）が、この畑で播く・刈る・観察する時期をどう決めるかを、出典付きの行と本人の記録から読む。
seed の今の記録には、天気の行がありません。

## 読み方

1. 気象は、`data` の行（出典と確認日付き）でだけ事実にします。出典の候補は、本人が確かめて `sources.md` に入れるまで
   根拠にしません。候補の名は「気象庁の平年値」「Open-Meteo」
2. 時期の読みは、本人の `did`、`saw`、`sow` の行と、同じ場所の前の観察の `change` から書きます
3. 判定の行（「今播くべき」）は書きません。材料（最終霜の目安、平年の降水、記録にある前年の同じ時期）と、
   次に何を見るかまでを書きます
4. `ask` の `sow` は、この章と 10 種、04 生物 を読みます
