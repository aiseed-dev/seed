# 10 種

## この章で読むこと

本人が種について聞いたときの立ち位置。預けていた種を、場所と年のロット、仲間との行き来に戻す、
という読み方です。

seed が種について持ち込むのは、二つだけです。種の素性と育ちを**記録に残す形**と、記録を**読むときの分け方**です。
何を播くかの判定は持ち込みません。

種の生物学（発芽の条件、受粉と交雑、休眠、寿命）の中身は、この章にはまだありません。作者が書く所として、
問いの形で置いてあります。そこが埋まるまで、あなたは知らないと伝えます。知識を作って埋めません。

## 読み方

### 種の素性

一つの種には、まず素性があります。名、入手先、採った場所と年、量です。

- 名は、作物の名と、品種の名か在来の名か。名が無ければ「名は無い」と残します
- 入手先は、採った・貰った・買った、のどれかです。貰ったなら誰から貰ったかは、本人の `record` にだけ残し、
  公開ファイルに書きません（`SKILL.md` の守ること）
- 採った場所と年、量は、本人の言葉のまま残します。量の単位も本人の言い方のままです
- 分からない物は、分からないと残します。あなたが推して埋めません。推したことは、確からしさを付けて `uncertain` に書きます

<!-- 本人が書く: 種の素性の付け方。名、入手先、採った場所と年、量のうち、何を必ず残すか。品種の名と在来の名をどう書き分けるか -->

### 場所と年のロット

- 種は「場所と年のロット」として読みます。どこで、いつ採った種で、その年にどう育ったか。育ち方は、
  本人の観察(`saw`)と、本人の合う／違うが残っている分だけを根拠にします
- ロットは、記録のフォルダーの `lots.md` に一行一つで残ります（`seed lot add`、`seed lot list`。`docs/記録の形.md` §15）。
  欄は `lot`（名）、`crop`、`variety`、`place`、`year`、`from`（親のロット。買った種なら `bought（店の名）`）、`note` です。
  本人が書く行だけで、あなたの行はありません
- ロットの名は英小文字・数字・ハイフン（`[a-z0-9-]+`）で、付け方は本人が決めます。例は `2026-kita-daikon`（年、場所、作物）。
  作物の名と場所は、`crop` と `place` に本人の言葉で入ります。公開ファイルに出せるのはロットの名だけで、場所は出ません（11 売る）
- 採った種は、次の年のロットになります。`from` に親のロットがあると、同じ系統の何年分かを並べて読めます

<!-- 本人が書く: 自分の畑で採った種の記録の付け方(ロットの名前の付け方、何を残すか) -->

### 播いてから

播いてからの記録が、そのロットの育ちになります。

- 何を、どこに、いつ、どう播いたか。直播か苗か、深さ、覆い、密度は、本人の言葉のまま写します。あなたが数字を補いません
- 出た日。出た割合の目安は、本人が数えたなら数を、数えていないなら「数えていない」と残します
- 同じロットの前の年と比べて、何が違ったか。比べるのは本人の `saw` どうしです。あなたは `change` の行に並べるまでです
- これが `plan.md` の `sow` の行と、観察の `## Record` の `did`、`saw` の行になります（下の「記録の形」）

<!-- 本人が書く: 作物ごとの発芽の条件。土の温かさ、湿り、光、播く深さのうち、何を見ればよいか。自分の畑で出なかった年に、何が違ったか(did、saw の言葉で)。読んだ一次資料(題名・著者・年・URL・確認日) -->

### 採る

- どの株から採ったか。本人が選んだ理由は、`record` に本人の言葉で写します
- いつ、どれだけ採ったか。乾かし方と置き場は、本人が書きます
- 選んだ理由が、次の年の育ちにどう出たかは、次のロットの観察が答えます。あなたは並べるまでです
- 採った種は、名の繋がった次のロットとして、素性の所から記録が始まります

<!-- 本人が書く: 自分の採り方。株の選び方、熟れの見方、乾かし方、選り分け方、置き場 -->

### 受粉の性質と交雑

採って繋ぐ種では、親と同じ形が次の年に出るかが、受粉の性質と、近くに何があったかで変わりえます。
その中身は、この章には書いてありません。作物ごとに、本人が書く問いは次のとおりです。

- この作物は自家受粉か、他家受粉か。花粉を運ぶのは虫か、風か
- 近くに、同じ種の別の品種や、野生の近縁があったか
- 隔離したか。したなら、何で隔てたか（距離か、時期か、覆いか）。隔離は要るか

あなたがするのは、観察の `plants`、`surroundings` の行から「近くに何が見えたか」を拾って、`uncertain` に並べるまでです。
交雑したかどうか、隔離が要るかどうかは書きません。花が写っていた観察では、近くの同じ仲間の花も撮ることを
`next_to_observe` に書いてかまいません。

<!-- 本人が書く: 作物ごとの受粉の性質(自家か他家か、虫か風か)と、交雑のしやすさ、隔離は要るか、要るなら何で。読んだ一次資料(題名・著者・年・URL・確認日) -->

### 休眠と寿命と保存

- 記録から並べてよいのは、何年目の種か、どこに、どう置いたか、発芽が落ちたか、です
- 休眠（採ってすぐは出にくい、など）と、種の寿命と、保存の仕方の中身は書きません。本人が書くまで、知らないと伝えます

<!-- 本人が書く: 作物ごとの休眠の有無と、その破り方。種の寿命。保存の仕方(乾き、温度、容れ物、置き場)。自分の記録と、読んだ一次資料 -->

### F1 の種と、採って繋ぐ種

- **F1 の種と、採って繋ぐ種は、分けて読みます。** 作者の見立て（01 の「福岡と川口」）では、福岡の作り方で育てると
  甘くて柔らかい野菜にはならず、今の F1 の種子の野菜には向きにくい。F1 は採った種が親と同じにならないので、
  「場所と年のロット」として繋ぐ種にもなりにくい。本人が F1 を蒔いたときは、そう書いて、その年の観察だけを残します。
  どの種が合うかは、本人の畑の観察と、食べたとき（調理を替えることを含む。12）が答えます。これは判定ではなく、
  読むときの分け方です
- 作者の言葉では「種子も慣行農業用とは違う（菌根菌等の微生物と共存しないといけない）」。これも見立てです。
  どの種が菌根菌とよく付き合うかの一次資料は、まだ `sources.md` にありません。あなたは書きません（菌根菌は 04 生物）

### 仲間との行き来

- 仲間との行き来は、人と繋がることです。seed は種の売買の仕組みを持ちません。種を交換する場は、
  本人が選びます
- 渡すときは、記録ごと渡します。ロットの名、採った場所と年、その年の観察（`did`、`saw`）。どの行を、どの粗さで
  渡すかは本人が決めます（11 売る）
- 貰った種は、貰った人から聞いた記録を、本人の言葉で `record` に写します。貰った人の名前と住所は、公開ファイルに書きません

<!-- 本人が書く: この土地の在来の種。誰が、どこで、どれだけの年月繋いできたか(本人が聞いた言葉で。人の名は record にだけ) -->

### 品種は写真で当てない

- Pl@ntNet が返すのは、種（species）の候補までです（`SKILL.md` の「草の名」）。品種（cultivar）は、写真から当てません
- 品種は、`sow` の行と、種のロットの名で残します。写真の作物の品種を問われたら、`sow` の行と `record` を引きます。
  無ければ、`uncertain` に「品種は写真からは分からない。播いた記録で確かめる」と書きます

### 福岡の種

- `sources.md` の 2 に書かれているのは、福岡の一反と、価格無用論までです。種の播き方は、そこにありません
- 福岡の種の播き方（粘土団子、直播）は、本人が『無』を読んで書くまで、あなたは書きません

<!-- 本人が書く: 福岡の『無』で、種の播き方について読んだ所(巻・ページ)と、自分の畑で試したこと(did、saw の言葉で) -->

### 種苗会社の説明と、判定の行

- **種苗会社の説明(カタログ、袋の裏、ウェブサイト)は根拠にしません。** 書かれた特徴は、本人の畑で
  確かめられた物ではありません。本人が引いたときは「種苗会社の説明では」と、それが説明であると
  分けて書き、確からしさは低くします
- 「この種を蒔くとよい」という判定の行は書きません。蒔いた年のロットの観察から、次に何を見るとよいか
  までを書きます

→ 種苗法の本文は図書室（`sources-law.md` の A）。条文は引いてよく、解釈と判定は書きません（`SKILL.md` の守ること）

## 記録の形

これは Claude の案です。決めるのは本人です。key は増やしません。`## Record` の key は、今のまま `did`、`saw`、`said`、
`note`、`ask` です。seed は種の売買の仕組みを持たないので、記録の形も、売り買いのためではなく、ロットを読むための物です。

`plan.md` の `sow` の行は、09 栽培計画の形のままです。ロットの名を文の中に入れます。

```
## Plan (claude-code)
- sow: 2025-kita-daikon のロットを、刈った筋に直播。時期は本人の言葉で [0.60]
```

観察の `## Record` には、播いたこと、見たこと、そのほかを、本人の言葉で写します。

```
## Record
- did: sow 2025-kita-daikon を刈った筋に直播。覆いは刈った草
- saw: 2025-kita-daikon の芽が筋に出ていた。数えていない
- note: 2025-kita-daikon は、前の年に自分の畑で採ったロットの種
```

採った種は、`did` の行の文の頭に `seed` と書き、新しいロットの名を入れます。新しいロットは、本人が `seed lot add` で
`lots.md` に足します（`from` に親のロット `2025-kita-daikon`）。

```
- did: seed 2026-kita-daikon を、本人が選んだ株から採った。乾かし方は本人の言葉で
```

行の形、`(none)`、本人の言葉を直さないことは、`SKILL.md` の「記録の書き方」と同じです。
