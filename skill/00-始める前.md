# 00 始める前 — 農地が無い所から

## この章で読むこと

本人が今どこに立っているか。そこから、どの章をどの順で読むか。この章は、**農地が無い人**の道筋を最初に
置きます。土地が無い、制度の言葉が読めない、始め方が分からない、という「自給農をするまでのハードル」が
一番高いのがこの人で、ここから始められれば、ほかの立ち位置の人はその途中から入れます。

すべては畑の写真を撮ることから始まります。自分の畑が無くてもかまいません。

## 最初に伝えること

- 畑が無くても始められること。最初にすることは、気になる耕作放棄地を道から一枚撮ることだけ
- あなた（Claude）は読みを書き、本人が合う／違うを付けること。決めるのは本人と畑
- 農地を借りる・買うには手続きがあること（農地法第 3 条。農業委員会の許可）。その中身は、作者が一次資料を
  読んで書いた aiai の「農業を始めるときの手続き」（`sources.md` 7）にあり、この手引きはそこを指す。
  結論（要る／要らない、借りられる／借りられない）はあなたが言わず、本人が窓口で確かめること
- 土地の所有者の名前・住所は個人情報で、本人の記録にだけ残し、公開しないこと

## 守ること

- 人の土地に入りません。道から撮ります。人や家、表札、車のナンバーが写らないようにします
- 「ここは借りられる」「買える」「手続きは要る／要らない」とは書きません。書くのは、何が見えて、何に拠るか、
  窓口で何を聞くとよいか、までです
- 所有者という個人を Web で探しません。調べ方は 13 にあり、調べるのは本人です
- 制度の事実は、`sources.md` にある物だけを根拠にし、出典と確認日を付けます。無い物は「本人が確かめる」と
  書きます

## 手順（農地が無い人）

最初に、本人に聞きます。決めつけません。気になる耕作放棄地があるか、通える距離か、何を作って暮らしたいか。
答えが無くても進めます。

1. **撮る。** 気になる耕作放棄地を、道から、座標の入る設定で撮ります。一枚でも、歩きながら何枚でも。
   記録に残るのは `photos/<日>/` の写真です
2. **読む。** 観察の前書きに `kind: candidate` を付けて、06 畑を読む の形で読みます。自分の畑と同じ形です。
   記録に残るのは `observations/<日>-<時刻>.md` の `## Reading` と、本人の合う／違うです
3. **筆と場所を調べる。** `## Data` の `parcel`（筆ポリゴンで田か畑と読まれているか、面積の目安）、`landform`、
   `hazard`、`geology`、`soil` を 02 地質と土 と 07 周りの物 の読み方で読みます。筆ポリゴンは位置と形の参考で、地番も筆界も
   権利も示しません。地番は法務局の地図で本人が確かめます（13）

   農地を紹介されたら、借りる・買うかの材料を並べます。`access`（道、通える距離、機械が入るか）、
   `sun_slope`（日当たり、向き、傾斜、影）、`surroundings`（周りの畑や家、獣の痕、ごみ）、`water`（用水と
   排水の口）、`plants`（草が語る土）と、上の `## Data` の行です（06）。材料として並べるだけで、
   「借りるべき」「買うべき」は書きません。決めるのは本人と畑です
4. **持ち主を探して、話す。** 近所に聞く、登記事項証明書を取る（13）。分かったことは本人の `## Record`
   （`said`、`note`）にだけ書きます。話した内容も本人の言葉で `said` に残します。持ち主にも seed を
   渡せます（持ち主は「貸す」の札で土地の記録を公開できます）
5. **借りる・買う手続き。** 農地なら農業委員会の許可（農地法第 3 条）。手順、農地バンク、eMAFF、
   下限面積要件が 2023 年 4 月 1 日に廃止されたことは aiai の「農業を始めるときの手続き」とその出典
   （`sources.md` 7）にあります。あなたは、本人が持って来た書類のどこに何と書いてあるか、窓口で何を聞くか
   までを書きます（13）。手続きの結論は言いません
6. **作業して、観察を続ける。** 借りる・買うことができたら、写真を撮ってから栽培計画 `plan.md` を立てます
   （09）。立ち位置は、菌根菌を活かす自然農法から始めること。畑ごとの判定ではありません。 したことを `did` に、見たことを `saw` に。同じ場所をまた撮ると、読みに
   `change`（前の観察からの変化）が付きます。何が効いたかは、`did` と `change` と本人の合う／違うで、
   本人の記録に溜まります（06）
7. **自給と、その次。** 採れた物、売ること、加工、手伝うこと（11、12）。最低限の貨幣は要り、最初の貨幣は
   手伝うことです（11）
8. **手引きを直す。** 「違う」の理由が溜まったら、`~/seed/skill/` のこの手引きを直します（08）。これが
   ビルダーの訓練の一周です

順は目安で、本人が先に進みたい所から読みます。

## ほかの立ち位置

| 今の立ち位置 | 最初にすること | 入る所 |
|---|---|---|
| 親族の土地がある | 本人が耕す場所なら、そこを撮る（`kind: own`）。まだ決めていないなら候補として撮る。親族と話すのは本人 | 手順 2 から。手続きは 5 |
| 耕作放棄地を持っている | 持っている土地を撮る。自分の畑として観察する | 手順 2 から。4 と 5 は要らない |
| 貸したい | 土地を撮り、観察を残す。公開ファイルの `next` の札に「貸す」を付けるかは本人が決める（11） | 手順 1〜3、そして 11 |

「借りる」「手伝う」の札も同じです。土地の持ち主が土地の記録を公開し、始めたい人が探して一言を送ります。
seed は権利も契約も扱いません。繋がった先の会話は Discord です。

## 候補地の観察の形

自分の畑でない場所を観察するときは、観察の前書きに `kind: candidate` を付けます。自分の畑なら `kind: own`
で、書かなければ `own` です。どちらかは本人が選びます。迷っていたら本人に聞きます。

```yaml
kind: candidate                  # own（自分の畑）か candidate（候補地）。無ければ own
```
