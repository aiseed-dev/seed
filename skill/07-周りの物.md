# 07 周りの物

## この章で読むこと

畑の外にある物(筆、歴史、地名)を、照会の `data` 行からどう読むか（地質、土壌、地形、標高、災害の区域は → 02 地質と土）。
`data` の行は出典付きの事実で、読みの行(仮説)とは分けて扱います。

## 読み方

→ key ごとに何を見るか、までを書くこと（結び付けは、本人が資料を読んでから）は 02 地質と土 の「読み方」の初め。

| key | 何の行か | これが分かると何を見るか |
|---|---|---|
| `parcel` | 筆ポリゴン(位置と形、面積、田か畑か) | 写真の範囲が、どの区画のどこか。境や権利は示さない(13) |
| `history` | 近くの史跡、昔の土地利用、記事 | 昔の畑や田、道、水路の跡が地表に出ていないか |
| `place_name` | 大字などの地名、由来 | 地名が語る水や土の様子が、畑で見えるか。由来は資料にある範囲だけ |

- 照会の点は、写真の座標の重心です。写真が畑の縁に寄っていると、重心も縁に寄り、`parcel` が「筆の外」と出る
  ことがあります。そのときは「筆の外」と決めず、`uncertain` に、重心が縁に寄っている可能性と、100 m 内の筆の数
  （田が何枚、畑が何枚）を書きます。どの筆かは、本人が公図か全国農地ナビで確かめます(13)
- データの出典の条件(筆ポリゴン、土壌図)は 13 を読みます

→ 「日本の公の研究データは、前提を添えて読みます」「行は一つの点の物」「照会が空の項目」は 02 地質と土。
