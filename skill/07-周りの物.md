# 07 周りの物

## この章で読むこと

畑の外にある物(筆、歴史、地名)を、照会の `data` 行からどう読むか（地質、土壌、地形、標高、災害の区域は → 02 地質と土）。
`data` の行は出典付きの事実で、読みの行(仮説)とは分けて扱います。筆ポリゴン、昔の空中写真、遺跡の報告書の資料も、ここで読みます。

## 読み方

→ key ごとに何を見るか、までを書くこと（結び付けは、本人が資料を読んでから）は 02 地質と土 の「読み方」の初め。

| key | 何の行か | これが分かると何を見るか |
|---|---|---|
| `parcel` | 筆ポリゴン(位置と形、面積、田か畑か) | 写真の範囲が、どの区画のどこか。境や権利は示さない(13) |
| `history` | 近くの史跡、昔の土地利用、記事 | 昔の畑や田、道、水路の跡が地表に出ていないか |
| `place_name` | 大字などの地名、由来 | 地名が語る水や土の様子が、畑で見えるか。由来は資料にある範囲だけ |

- 照会の点は、写真の座標の重心です。写真が畑の縁に寄っていると、重心も縁に寄り、`parcel` が「筆の外」と出る
  ことがあります。そのときは「筆の外」と決めず、`uncertain` に、重心が縁に寄っている可能性と、100 m 内の筆の数
  （田が何枚、畑が何枚）を書きます。どの筆かは、本人が公図か全国農地ナビで確かめます(13)
- データの出典の条件(筆ポリゴン、土壌図)は 13 を読みます

→ 「日本の公の研究データは、前提を添えて読みます」「行は一つの点の物」「照会が空の項目」は 02 地質と土。

### 筆、昔の土地利用、史跡を読む資料

本人が `parcel` と `history` の行の先を読みたい時に、出典と確認日を付けて伝える資料です。

| 読むこと | 資料（`sources.md`） | 引く所 |
|---|---|---|
| `parcel` の元のデータ | 43 | 筆ポリゴンが何から作られたか（耕地面積調査などの母集団情報）、公開サイトでの閲覧、地図表示で形を単純化していること、利用規約 |
| 昔の土地利用 | 44 | 1930 年代からの空中写真（1945 年前後の米軍の写真を含む）。地図・空中写真閲覧サービスで、同じ場所を年代ごとに並べる |
| 近くの遺跡と発掘の記録 | 45 | 全国文化財総覧の発掘調査報告書と遺跡の抄録。都道府県ごとの発行機関から探す |

- 空中写真は、撮った年と季節で写り方が変わり、国土の約半分しか撮っていません（44）。その年に田だったか畑だったかは、
  写真の写りを読んだあなたの行で、確からしさ付きです。`data` にするのは、写真の名（撮った年、整理番号）と確認日までです
- 記録の行: 資料から写す物は `## Data` に `history` の行で（`- history: 空中写真 <撮った年>、<写真の名>（出典: 国土地理院 地図・空中写真閲覧サービス、確認日 …）`）。
  その写真に何が見えるかは `## Reading` のあなたの行。近所で聞いた昔の話は本人の `said`
- 写真から読める所: 畦の跡、石垣、段、水路の跡、古い道（`surroundings`、`water`、`access`）
- 写真から読めない所: その跡がいつの物か、誰が作ったか、遺跡の範囲（報告書と、市町村の文化財の担当で確かめます）
