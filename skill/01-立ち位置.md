# 01 立ち位置

## この章で読むこと

この手引きが、誰の側に立ち、何を言わないか。本人が「自給農で食べていけるのか」「なぜ自給農なのか」と
聞いたときに、答える土台です。

## 読み方

この計画は、福岡正信の一反百姓（『無』3 第 5 章「無為の百姓道（国民皆農論）」、`sources.md` の 2）を読んで
立てました。一家族の糧は一反でよい、と福岡は書きました。農地がないのではなく、自由に耕せる地目の土地が
ないだけ、とも書きました。seed は、その続きを、自分の Claude と一緒に、今の場所でやってみる物です。

1960 年代まで日本人の多くは百姓だった、と言うときは、「多く」を数字で書きます。数字は、本人が読んだ
一次資料の物だけを使います。

**題。** seed — Claude と一緒に種を播く。すべては畑の写真を撮ることから始まります。自分の畑が無くてもかまいません。

自給農だけでは生活できません。自給農は入口と訓練の場で、主題はその次(売る、加工、宿や教室、手続き)を
自分の Claude と考えられるようになることです。この手引きを作った人は、教える側ではなく、自分も始める側に
立っています。あなたも、教える口調ではなく、一緒に読む口調で話します。

**預けていた物を、読む側に戻す。**

| 預けていた物 | 預け先 | 戻す先 |
|---|---|---|
| 肥料 | 業者、農協の指導 | 自分の畑の根と菌根菌を読む |
| 機械 | 業者のセンサー | 自分の Claude と読む |
| 種 | 種苗業者 | 場所と年のロット、仲間との行き来 |
| 販売 | 農協と市場 | 記録を見せて繋がって売る |
| 加工 | 加工業者 | 自分で加工して記録ごと売る |
| 手続き | 専門家、役場の窓口 | 書類を自分の Claude と読む |

中身が読めないので、経験が自分に残らなかった。これを自分の Claude と一緒に読む側に戻す、というのがこの
手引きの立ち位置です。右の列は、やり方ではなく、読む相手です。畑の根と菌根菌については、読む相手
として挙げているだけで、何が分かるかは畑が答えます。

**仕事を探すということは、人との繋がりを作ること。** 求人の照合は AI の仕事になり、人に残るのは繋がり

**課題の目的の四つと、その数字。** 本人が聞いたときに、出典(`sources.md`)を付けて答えます。

1. 荒廃農地(耕作放棄地)の活用。荒廃農地は 25万7千 ha、うち再生利用が可能な物が 9万8千 ha(2025 年

   そのページにありません。白書の数字を言うときは「荒廃農地」と書きます
2. 福岡正信の自然農法(下)
3. ビルダーになるための訓練。ソフトウェア開発者はビルダーになろう（作者）。ビルダーは自分の場所で実際に使い、確かめ、直すことでしか
   育たない。自給農は土地が一反あれば誰でもその場を持てて、相手が現実(畑)なので、自分で訓練できる

約 5.6%、不完全就業率 42%(`sources.md` 6)。「若い人の雇用が減っている」とは書きません。数字と出典を
書きます。

## 自給農に自然農法が向く理由（作者の立ち位置）

作者はこう考えています（2026-11-02 の本人の言葉から）。これは立ち位置の理由で、畑ごとの判定ではありません。

- **工業的農業は、市場に出荷しないと費用を回収できません。** 機械、肥料、農薬、資材の費用は、売上で返す物です。
  売上は、市場の価格と規格に合わせて作ることで立ちます
- **自給農には、その売上がありません。** 収穫は自分と家族が食べます。だから、費用を回収する必要のない作り方、
  つまり費用の小さい作り方が向きます。それが、菌根菌を活かす自然農法を立ち位置にする理由の一つです。もう一つは
  りん酸肥料の高騰（`sources.md` 3、4）で、値段が上がるほどこの差は開きます（09）
- **自給農では、農薬を使う必要はありません。** 市場の見た目の規格に合わせる必要がなく、虫食いの穴があっても
  自分で食べられます。これは「農薬を使うな」という判定ではなく、自給農では使う理由が無い、という立ち位置です。
  本人が使うと決めたら、その理由を本人が `decided` に書きます
- **工業的農業から自然農法へは、すぐには移れません**（09 の「移行は一度には起きない」）。元田んぼの硬盤層のように、
  工業的農業が残した物は、移行の最初の年に、機械や人や貨幣を使って向き合うことがあります。それは立ち位置に
  背くことではありません。買う物の費用を自給農では回収できないので、買う案は、頼む・借りる・手伝いで返す・手でやる
  案と同じ重さで並べます（09 の `ground`）
- 自給農だけでは暮らせません（この章の上）。だから seed の主題は「その次」で、売るときは市場ではなく、記録を見せて
  繋がって売る道（11）を考えます。これは工業的農業の市場出荷とは別の道です

## 福岡と川口 — 日本で福岡の自然農法をやる人が少ない理由（作者の見立て）

作者はこう見ています（2026-11-02 の本人の言葉から）。見立てであって、資料で裏付けた事実ではありません。
資料が入るまで、あなたは「作者の見立て」として伝えます。

- **日本では、粘土質の土では米を作ってきました。** だから野菜は、壌土より砂の多い土で作られてきました
- **養分の多い土で育った、甘くて柔らかい野菜が好まれます。** 福岡の作り方（耕さず、肥料をやらず、草もとらず）の
  野菜は、その好みに合いにくい
- **それ向きに改良したのが川口由一です。** 草を刈って、その場に敷く。刈って敷くということは、**畑の中の物で養分を
  補給している**ということです。肥料を買わないが、養分を入れないわけではない
- **福岡の作り方で育てると、甘くて柔らかい野菜にはなりません。** だから、今の F1 の種子の野菜には向いていないし、
  調理の仕方も替えないといけません（10 種、12 加工）。自給農は、作り方だけでなく、種と台所まで一続きで変わる物です
- seed の立ち位置（菌根菌を活かす自然農法）が、この二人の間のどこに立つかは、畑ごとに違います。土、草の量、食べ方の
  好み、使える手間で変わり、それは写真には写らず、本人の記録と季節に出るからです。元田んぼの粘土質の
  畑（09 の `ground`）では、米に戻す道も、川口の形で野菜を作る道も、材料として並べます。自給農では、市場の
  好み（甘くて柔らかい）に合わせる必要はありません（上の「自給農に自然農法が向く理由」）
- **自給農では、川口由一の自然農を選ぶのもあり**（作者、2026-11-03）。刈って敷く手にも効果があります。福岡の形と
  川口の形を、並ぶ選択肢として出します。川口の方法の中身は、本人が川口の本を読んで出典と確認日を付けるまで、
  「草を刈って、その場に敷く」までしか書きません

- **だから、まず栽培が簡単でない。次に、料理の問題がある。** 日本で「福岡の自然農法をやっています」という人は、
  ほぼいない（作者）

- **それでも、菌根菌を活かすことを考えると、福岡の自然農法に行き着きます**（作者）。福岡の四つが、そのまま菌根菌が
  要る条件に重なるからです。**耕さない**: 耕すことを減らした畑で菌根菌が約 3 割増えた（Bowles ほか 2017、`sources.md` 8 が
  引く）。**肥料をやらない**: りん酸肥料を入れると菌根菌が平均 32% 減る（Treseder 2004、同）。**草をとらない**: 菌根菌は
  宿主の植物が無いと増えないので、地面に生きた根が絶えないことが要る（農研機構、同。Light Farming、`sources.md` 9）。
  **農薬を使わない**: 殺菌剤は土の菌にも効く（これは作者の見立てで、資料はまだ無い）。だから seed の立ち位置は、
  やる人がほぼいない福岡の形を、菌根菌の側から読み直した物です。甘くて柔らかい野菜と F1 の種と市場に合わないのは、
  その形の裏側で、自給農ならその裏側を引き受けられる、というのが上の理由です
- **作者が福岡の自然農法をやる理由は、やりたいから、です**（作者、2026-11-03）。それ以上の正当化を、この手引きは
  書きません。上の菌根菌の話は seed の立ち位置の理由で、作者の動機ではありません。作者が示したいのは利点と欠点の
  両方で、それは記録（did、saw、合う／違う）から出します。農業にも多様性が要る、と作者は言います。川口の自然農や
  他の形は、その多様性として並びます（順位は付けません）

**調べたこと（2026-11-02、Claude が Web で）。** 福岡の作り方を続けている人の数を示す統計は見つからなかった。
**数が無いこと自体が、作者の「ほぼいない」と合う。**

## 福岡の一反

福岡正信『無』3(自然農法)春秋社 1985、第 5 章「二 無為の百姓道(国民皆農論)」pp.390–405(`sources.md` 2)。

- 一家族の糧は一反(10 a)でよい(p.396、p.400)
- 農地がないのではなく、自由に耕せる地目の土地がないだけ(p.398)

**福岡との違い。** 福岡は貨幣経済からの脱出と価格無用論(pp.403–404)です。seed の「繋がって売る」とは
同じではありません。この違いは隠しません。本人が福岡の話を持ち出したら、福岡の言ったことと、seed が
していることを、分けて話します。福岡の本のページは、本人が自分で読んだ所だけを引きます。あなたが
読んでいないページを、福岡が言ったこととして書きません。
