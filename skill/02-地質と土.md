# 02 地質と土

## この章で読むこと

畑の下と周りの地質、土壌、地形、標高、災害の区域を、照会の `data` 行（出典付き）と、本人が畑で見たことからどう読むか。元田んぼの硬盤層のように、seed の立ち位置が土の現実に会う所も、この章で読みます。

## 読み方

`## Data` と `place.md` の行は、key ごとに、これが分かると何を見るかを考えます。ここに書くのは、
**何を見るか**までです。この地質だからこの草、のような結び付けは、裏付けの資料を本人が読んでから
(`<!-- 本人が書く -->` の所が埋まってから)書きます。それまでは、確からしさの低い仮説として
`uncertain` か `basis` に書きます。

| key | 何の行か | これが分かると何を見るか |
|---|---|---|
| `geology` | 畑の下の岩の種類 | 土の色や石の混じりを撮るとき、地質の名前と並べて見る。畑の土が地質の名前と違うと分かったら、畑のほうが正しい |
| `soil` | 土壌図の分類 | 地図の分類と、畑の土の色、湿りが合うか。合わなければ誤りかもしれない(13 の注意) |
| `landform` | 地形の分類(段丘、扇状地、氾濫平野など) | 水が溜まる所か、抜ける所か。`water` の行で何を見るか |
| `elevation` | 標高 | 周りより高いか低いか。水の流れ、霜や冷気が溜まるかを、次の観察で見る |
| `hazard` | 災害の区域(土砂、浸水)の内か外か、近い区域までの距離 | 水の通り道、斜面、過去の水の跡が写っていないか。避難や手続きの判定は書かない |

- **日本の公の研究データは、前提を添えて読みます。** 農研機構、農水省、都道府県の指針などのデータは、
  工業的農業(施肥、耕起、単作、農薬)を前提に取られています。無施肥・不耕起・混植の畑に、そのまま
  当てはまるとは限りません。`soil` の行(農研機構の土壌図)を `data` に使うときは、この前提を一行添えます。
  土壌図に付く施肥基準や目安の値を、その畑の目標にしません
- 行は一つの点の物です。畑全体が同じとは限りません。座標の広がり(`extent_m`)と合わせて読みます
- 照会が空の項目は、無かったのではなく、分からなかったのかもしれません。「無い」と書かず、
  「照会に出ていない」と書きます

→ 筆、歴史、地名の行と、データの出典の条件は 07 周りの物。
→ 写真に写る地表の色と湿り、水の見方は 06 畑を読む の「写真から見る物」。

## 元田んぼの硬盤層: 立ち位置が現実に会うところ

日本の畑の多くは元田んぼです。田んぼは水を保つために、作土の下（15〜25 cm）に硬い層（鋤床層、硬盤層、耕盤）を
作ってきました。この層は、根と水を止めます。「耕さない」という立ち位置は、ここで現実に会います。手引きは
決めません。本人が決められるように、**案と、それに要る物と、確かめることを並べます。** `ground` の行です。

並べる案（本人の畑に合わせて増減する）:

| 案 | 要る物 | 確かめること・知ること |
|---|---|---|
| 機械で一度だけ破砕する（サブソイラ、プラソイラ、心土破砕） | トラクター（買う／中古／借りる）か、作業を頼む相手（近所の農家、JA の作業受託、業者）。貨幣か、手伝いの行き来（基本計画 §1 の「最初の貨幣は手伝うこと」） | 層の深さと厚さ（棒を押した深さ、掘った穴）。土性（シルト質埴土なら、割れても戻りやすいかを本人が調べる）。周りが田なら、破砕で水が抜けて隣に障りが出ないか。値段と頼める相手は、本人が窓口と近所で聞く。数字は aiai の `nouka-keikaku` に |
| 深い根の植物で時間をかける（緑肥） | 種と、数年の時間。すぐには割れない | どの植物が硬い層を通るかは、資料がまだ `sources.md` に無い（候補は `sources-regenerative.md` の E）。本人が読んでから書く。雨の後に水が層の上に溜まるか |
| 手で部分的に（播く所だけ、スコップや鍬で穴を抜く） | 人の力と時間。道具 | 一か所にかかる時間を測って、面積と比べる。シルト質埴土で冬に硬いか、湿ったときに抜けるか |
| 壊さず、層の上で作る（浅根の物、畝を高くする） | 畝を作る土と労力。排水の出口 | 層の上に水が溜まる所。畝の高さで足りるか。夏の隣の田の水が入るか |
| 一部だけ壊して比べる | 上のどれかを、畑の一部に | 壊した所と壊さない所を、同じ作物で並べて、根と育ちを本人が見る（08 の一周） |
| 田に戻して米を作る（粘土質の元田んぼなら） | 水（用水の口と水利、13 手続きと農地）、畦の直し、苗か種、刈る人手。硬盤層はそのまま活きる | 日本では粘土質の土では米を作ってきた（01 の「福岡と川口」）。用水が引けるか、周りの田と同じ時期に水が来るか、水利組合に聞くこと |

- 案は、年を分けて書けます。「一年目: 機械で一度、または一部だけ手で。二年目から: 壊さない」のように、移行の段階として。
  段階の区切りを決めるのは本人で、区切りごとに観察（08 の一周）で確かめます
- 案のどれが「よい」とは書きません。要る物（機械、人、貨幣）を隠しません。トラクターを買う案は、買う案として
  書き、値段と置き場と維持を本人が確かめることとして添えます。頼む案、借りる案、手伝いで返す案も同じ重さで並べます。
  自給農には買った物の費用を回収する売上が無い（01）ので、買う案だけを先に置きません
- 土性は、`## Data` の土壌図（次表層の土性）と、本人が手で確かめたこと（握って、ひもにして）を並べます。土壌図は
  点の値で、工業的農業を前提にした地図です（この章の読み方）
- 硬い層の深さは、本人の record（棒が入った深さ、掘った穴）だけを根拠にします。推測の深さを書きません
- 案を比べる所に、りん酸肥料の値段の動き（`sources.md` 3、4）を添えます。値段が上がるほど、肥料に寄る道の費用は上がり、菌根菌を活かす道の分が良くなります。これは立ち位置の理由と同じ数字で、案の優劣を決める物ではなく、本人が比べるときの材料です。値段は月ごとに変わるので、確認日が古ければ本人が引き直します
- 日本の公の資料（農研機構、農政局、県の手引き）の排水と心土破砕の技術は、大豆や麦の転換畑のために、耕起と施肥を
  前提に書かれています。機械と層の性質の説明は使えますが、その後の作り方まで持ち込みません
