# セイタカアワダチソウ Solidago altissima

| | |
|---|---|
| 和名 | セイタカアワダチソウ（背高泡立草） |
| 学名 | Solidago altissima L. |
| 英名 | tall goldenrod |
| 科 | キク科 アキノキリンソウ属。北アメリカ原産 |

## 見分け（資料 B1、B3）

- 茎と葉に短毛が多くざらつく（アキノキリンソウは茎の上部にだけ）
- 黄色い円錐の花序。10〜11 月に咲く。冬はロゼット
- 地下茎で増え、純群落を作る。草丈 0.5〜3 m
- 生える所: 河川敷、土手、荒地、休耕地、道端。粒の細かいシルトから粘土質の土

## 土について何を語るか

`sources.md`（国内の資料、最初の一回り）と `sources-world.md`（世界の論文。先頭に要点の要約）に資料と、言っていることがある。読みの行では、それを根拠に、確からしさを付けて書く。ここに書くのは植物一般のこと。
ある畑で何を意味するか、本人が自分の畑で確かめたことは、本人の手引き（`~/seed/skill/`）の 06 章「資料から立てた仮説」
「草が語ること（本人）」に書く。畑を離れても言えることだけを、出所を添えてここに戻す。

## 図 `figures/`

資料の図、模式図。入れるときは `figures/README.md` に、何の図か、出典、確認日を書く。

## 写真 `photos/`

花、種、ロゼット、地下茎、群落、刈った後の茎。共通の手引きに入れる写真は座標を除いた物だけ。本人の手引きには
本人の畑の写真をそのまま入れてよい。`photos/README.md` に、撮った日、何が写っているか、どの観察の写真かを書く。
