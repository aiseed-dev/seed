# 草と作物 — 植物ごとの資料

植物ごとに一つのディレクトリーを持つ。文だけでなく、図と写真が大切だから。

```
plants/
  README.md                      この文
  <学名のスラグ>/                 例: miscanthus-sacchariflorus, solidago-altissima
    README.md                    和名・学名・見分け・何を語るか・図と写真の案内
    sources.md                   国内の資料と、言っていること（番号 A1, B1 …）。本人が読んだ物は根本の sources.md へ
    sources-world.md             世界の論文（番号 W1 …）。先頭に要点の要約（植物一般のこと）
    figures/                     図。figures/README.md に一覧
    photos/                      写真。photos/README.md に一覧。共通の手引きでは座標を除く
```

- ディレクトリー名は学名の小文字をハイフンで繋いだ物（どの言語の人でも同じ名になる）。和名は README に
- 読みの行で根拠にするときは `basis` に「plants/<スラグ> A2」のように書き、本人が読むまで確からしさは 0.6 を超えない
- 新しい植物を足すときは、同じ五つ（README、sources、sources-world、figures、photos）を作る。本人の畑の草の名前が決まったら
  （06 章の「本人が書く所」の、自分の畑の草の名前）、その植物のディレクトリーを本人の手引きに作る
- **共通の手引きの植物のディレクトリーには、その植物一般のことだけを書く。** 「この畑のオギは硬盤層の上で生きている」のような、
  ある畑での意味は、その人の手引きの 06 章の「本人が書く所」（草の種類と高さが、土の何を語るか）に書く。この植物の資料は、
  その畑のためにだけあるのではない。共通に戻すのは、畑を離れても言えること（例: 秋に刈っても地下茎が残れば翌年に戻る）だけで、
  出所（誰の畑の、いつの記録か）を添える
- 集めた日 2026-11-02 の二つ（オギ、セイタカアワダチソウ）は、作者の畑で面を占めている草から始めた
