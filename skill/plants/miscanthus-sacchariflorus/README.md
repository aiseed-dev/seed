# オギ Miscanthus sacchariflorus

| | |
|---|---|
| 和名 | オギ（荻） |
| 学名 | Miscanthus sacchariflorus (Maxim.) Hack. |
| 英名 | Amur silver grass |
| 科 | イネ科 ススキ属 |

## 見分け（資料 A1、A2、A3）

- 地下茎で広がり、茎が 1 本ずつ地面から立つ。**株立ちにならない**（ススキは株立ち）
- 小穂に**芒（のぎ）が無い**（ススキは有る）
- 茎は堅くササの幹のよう。穂は銀白で、ススキより大きい。草丈 2〜3 m
- 生える所: 川原の低水敷、氾濫原、放棄水田。水際から台地へ、マコモ → ヨシ → オギ → ススキ の順

## 土について何を語るか

- **秋に一度刈っても、地下茎が残れば翌年に 2.5〜3 m に戻る**（作者の畑の記録、2026-11-02: 前の年の秋に刈り、ほぼ 1 年で戻った）。「年 1 回刈ると数年で衰える」
  （`sources.md` A2）は刈る時期を言っていない。秋の刈り取りは地下茎の蓄えを傷めず（道総研 A4、英国 W26）、伸びている夏に刈ると
  弱る（W38、A4）。オギの大きさは、刈られなかった年数ではなく、残った地下茎の蓄えと、その年の水と光を言う

`sources.md`（国内の資料、最初の一回り）と `sources-world.md`（世界の論文。先頭に要点の要約）に資料と、言っていることがある。読みの行では、それを根拠に、確からしさを付けて書く。ここに書くのは植物一般のこと。
ある畑で何を意味するか、本人が自分の畑で確かめたことは、本人の手引き（`~/seed/skill/`）の 06 章「資料から立てた仮説」
「草が語ること（本人）」に書く。畑を離れても言えることだけを、出所を添えてここに戻す。

## 図 `figures/`

資料の図、模式図（地下茎と株立ちの違い、水際からの群落の並び）。入れるときは `figures/README.md` に、何の図か、
出典、確認日を書く。資料の図を写すときは、その資料の利用条件を確かめる。

## 写真 `photos/`

この植物の写真。穂、株元、地下茎、群落、季節ごと。共通の手引きに入れる写真は、座標を除いた物だけ
（`seed` の `photos.strip_exif`）。本人の手引きには、本人の畑の写真をそのまま入れてよい。`photos/README.md` に、
撮った日、何が写っているか、どの観察の写真かを書く。
