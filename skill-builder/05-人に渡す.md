# 05 人に渡す

## この章で読むこと

足した物を、仲間のビルダーに渡す形。手引き 08 章「直した手引きを、人に渡す」と同じ考えで、渡すのは作り方（コード、
プラグイン、手引き）で、記録ではありません。

## 渡す物の形は二つ

| 足した物 | 渡す形 |
|---|---|
| 記録のフォルダーのプラグイン（`plugins/<名>.py`） | GitHub の自分のリポジトリに、そのファイルを置く。受け取った人は自分の `plugins/` に置く |
| フォークした seed の直し | 自分のフォークに置く。元の seed（https://github.com/aiseed-dev/seed ）へ pull request で戻す道もある（README「直した物は戻せます」） |

フォークした seed は、その人の物で、その人の Claude が動かします。元の seed の Claude が、あなたのアプリのコードを
書き換える事はありません（利用マニュアル §11）。

## 置く物、置かない物

- 置くのは、コード、テスト、手引き、`docs/` の直しです
- 置かない物は、記録のフォルダーの中身です: `fields/`、`observations/`、`photos/`、`originals/`、`videos/`、`place.md`、
  `plan.md`、`next.md`、`connections.md`、`public/`、`public-home/`、`lots.md`、`ledger.md`、`weather/`、`procedures/`、
  `origin/`、`grow/`、`seed.toml`、`home.toml`、`CLAUDE.md`、本人が書き足した `skill/`。`~/.config/seed/credentials.toml` も
  置きません
- 記録のフォルダーのプラグインを渡す時は、`plugins/` のファイルだけを別のリポジトリに写して置きます。記録のフォルダーを
  そのまま GitHub に上げると、上の物が全部出ます

## 置く前に見る物

- 本名、住所、電話番号、メール、土地の所有者の名前を、コードの中の見本や文に書いていないか（手引き 08 章と同じ）
- 本物の座標を見本に使っていないか。テストの座標の見本も、本人の畑の座標でない物にします。細かい座標らしい数の対は
  `records.fine_coords(文)` で探せます
- 鍵、token、招待コードの値が無いか（04）
- 見た結果を本人に伝えてから、本人が push します。外へ出す物なので、出す前に本人が全部を読める形にします

## どこを直したか、なぜ直したかを残す

- 何を足したか、本人のどんな言葉から足したか、畑で何が足りなかったかを、リポジトリに文で残すと、受け取った人が自分の畑に
  合うかを読めます（手引き 08 章の「直した手引きを、人に渡す」と同じ）
- 記録の形を変えたなら、`docs/記録の形.md` の日付付きの節（02）が、そのまま説明になります
- 外と話す機能なら、何が外へ出るかを一行書きます（04 の表の形）

## ライセンス

seed は AGPL-3.0-or-later です（`LICENSE`、`pyproject.toml`）。同梱のコードのファイルは頭に
`# SPDX-License-Identifier: AGPL-3.0-or-later` の一行を持っています。足したファイルも同じ一行で始めます。フォークして
自分の物にする事は、このライセンスが許しています（利用マニュアル §11）。

## みんなに配る物にする時

足したプラグインが、ほかの畑でも使える物なら、同梱（`src/seed/plugins/`）にする道があります。同梱の三つ（land、
procedure、weather）は、この形で入っています。

- 文を `strings.py` の ja と en に移す（01）
- `tests/` にテストを足し、同梱の並びを見ているテストを直す（03）
- 設計書 §5.11 の同梱の並びに一つ足す
- スマートフォンの包みに入る物だけを使う（01）
- スマートフォンで画面を確かめるのは、README の「スマートフォンで試す」の手順です（USB で繋いだ Android に
  `flet debug android` で入れる）

## 壊れた所も渡す

手引き 08 章の「二つ目の輪」と同じで、足して壊れた所（記録が消えかけた、鍵を出しかけた、網に出たまま画面が止まった）は、
本人の記録に `did`、`saw` の行で残すと、次に足す時の材料になります。渡す文にも書けば、受け取った人が同じ所で
躓かずに済みます。
