# 07 週の定例（元の kagi 手引き §4f。連載 第 11 章の「週 15 分」）

```bash
kagi weekly
```

機械の表の全部の機械の写しを取り直し、在庫、機械（前の写しから増えた・消えた直す物）、出した token、記録を一枚にして、作業の場所の `weekly-<日>.md` に書く。入れなかった機械は、その事が末尾に出る。先週の紙と並べて読む。

良い形の出どころは、連載「Claude と一緒に育てる Debian サーバー」（ https://aiseed.dev/debian-server/ ）。どの章がどの行に当たるかは設計書 §3.4b。直し方が分からない行は、その章を読むか、行をそのまま Claude に渡す。
