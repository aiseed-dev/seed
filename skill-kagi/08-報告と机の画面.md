# 08 一枚の報告と机の画面（元の kagi 手引き §5、§5b）

## 5. 一枚の報告

```bash
kagi report
```

在庫の数と期限、口の差、走査の数、記録の検証。これを読んで「合っている」と言えたら、次の歩（置き場、控え、根と二人。鍵の管理 §5）へ。報告は印刷して紙に残してもよい（K-10 の紙の隣）。

## 5b. 机の画面

`kagi app --dir ~/kagi-data` で、係の PC に窓が一つ開く（Flet の PC 版。網には出さない）。`flet` が要る（`pip install -e '.[app]'`）。
画面は四つ。**機械**: 上の釦で機械を選ぶ（`直す 9`、`よし`、`写し無し`）。「写しを取る」で今の形を読み、直す物が一件ずつ、手の文と並んで出る。手の右の印で写し、機械の端末に貼る。終わったら、もう一度「写しを取る」。一台目は「機械を足す」の欄から。**鍵**: 鍵の一覧と「鍵を足す」（渡すのは `.pub` だけ）。**在庫・口・記録**: 在庫・口・走査・記録の札と報告の釦。在庫の下に「サーバーの外の鍵」と「在庫表に一件足す」。**人の出入り**: seed のサーバーの門（下）。
動いているべきサービス（seed のサーバーなど）を機械の `services` に書いておくと、止まった時に「直す」に出る。口は `ss -ltnp` の写しを選び、走査は場所を選ぶ。記録は actor・action・detail を書いて「一行足す」（署名の鍵は §3）。
報告の釦は `report-<日>.md` を作業の場所に書き、画面にも出す。鍵の値は画面に出ない。

**人の出入り。** 要るのは、サーバーの URL（`https://seed.example` のような https。http は断る）と、管理者の token（機械の上で `seed token add "<自分の呼び名>" --scope admin` で出した物）。「繋ぐ先」に入れて「保存」すると、作業の場所の `seed-admin.json` に持ち主だけが読める形（600）で置かれ、画面には「入っています」とだけ出る。在庫表にこの token の一件が無ければ、そう出るので「在庫表に一件足す」から書く（値は書かない）。
上から、今の状態、気を付ける事（打つコマンドは右の印で写し、サーバーの端末で読んでから打つ）、人に渡す token、公開された記録、操作の記録。操作の記録には、誰が何をしてどうなったかが人の言葉で並ぶ（deb2 経由で Claude と話した行は「Claude と話した」、結果は「通した」か「断った: …」）。token は、渡す相手の名前、できる事、期限（1〜365 日。管理者は短く 30 日が既定）を入れると「出す」が押せる。出た token は一度だけ出るので、写してその人にだけ渡す。取り消す、全部取り消す、受け付けを止める・再開する、取り下げる、一言を消すは、どれも二度押し（一度目で釦が「本当に…」に変わる）。止めている間は、どの画面でも上に赤い帯が出る。ここでした事は kagi の記録にも一行ずつ残る（token の値は書かない。署名の鍵が無い時はその事が出る）。

**サーバーの外の鍵。** 「人の出入り」で読んだ、サーバーに Claude と Pl@ntNet の鍵が在るか無いかを、在庫表の行と並べる。在庫表の行は、名か置き場に `anthropic`（か `claude`）、`plantnet` を含む物がその鍵の一件。サーバーに在るのに在庫表に無ければ「直す」なので、「在庫表に一件足す」で、名、置き場、持つ人、役、期限、なくした時、漏れた時を書く。値らしい物を貼ると断られる。回す周期は欄に無いので、足した後に `inventory.toml` をエディタで開いて `rotate_days` を書く。
