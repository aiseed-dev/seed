# 00 形

## この章で読むこと

プロジェクトフォルダーの根と畑に何が在るか。seed が読む物と、読まない物。畑の中の物が根の物に勝つ所。
重い物の置き場。秘密。形は `docs/記録の形.md` §1 と §19 で、この章はその要点と、見直しで迷う所です。

## プロジェクトと畑

プロジェクトフォルダーは `seed.toml` の在るフォルダーです（既定 `~/seed`）。畑が一つなら、根そのものが畑です。
畑が二つ以上なら、畑は `fields/<畑の名>/` に一つずつ在り、根には記録の中身（`observations/`、`photos/` など）を置きません。

```
~/seed/                       プロジェクト（seed.toml の在る所）
  seed.toml                   設定。プロジェクトに一つ。畑の中には置かない
  CLAUDE.md                   Claude Code をここで開いた時の決まり（seed init が書く。本人の物）
  skill/                      手引きの写し（本人が直す物）
  plugins/<名>.py             本人の画面（無くてよい）
  home.toml                   家のサーバーの招待コード。秘密（開かない）
  public-home/                家のサーバーの公開の置き場（seed home が使う）
  notes/                      本人と Claude の覚え。seed は読まない（2026-11-08 から）
  fields/<畑の名>/            畑一つ
    observations/  photos/  videos/  place.md  plan.md  next.md  connections.md  public/
    origin/  grow/  lots.md  ledger.md  weather/  procedures/
    notes/                    この畑の覚え。seed は読まない
    skill/  CLAUDE.md  plugins/   畑だけの物が要る時だけ（下の「畑の物が勝つ」）
```

- 一覧 `~/.config/seed/fields.toml` は、別の場所に在るプロジェクトに名を付けて切り替える物です（記録の形 §19）。
  プロジェクトの中の畑は、一覧に書かなくても `seed field list` に出ます
- 今の畑は `seed.toml` の `field` です。`seed field use <名>` で変え、`seed field use all` でプロジェクト全体にします

## seed が読む物と、読まない物

| 読む | 読まない |
|---|---|
| `observations/*.md`、`photos/`、`videos/` の `.json`、`place.md`、`plan.md`、`next.md`、`connections.md`、`public/`、`skill/`、`CLAUDE.md`、`plugins/*.py`、`seed.toml` | `notes/`、形の外のフォルダーとファイル（`uploads/` のような取り込む前の物、手で置いた写真） |

形の外に置いた写真は、アプリの写真の画面にも、Claude の読みにも出ません。写真は取り込んで（02）`photos/` に入れます。

## 畑の物が根の物に勝つ

`skill/`、`CLAUDE.md`、`plugins/` は、畑の中に在ればそれを使い、無ければ根の物を使います。**合わさりません。**
畑の中に `skill/` が一つでも在れば、その畑の読みは根の `skill/` を一行も見ません。

だから、畑の中の `skill/` は「その畑だけの節が在る時」にだけ置きます。外のフォルダーを畑として迎えた時（03）は、
そのフォルダーに在った古い手引きが畑の中に残り、新しい手引きより先に使われます。どの手引きが使われているかは
`seed skill-path --field <畑の名>` が出します（04）。

## 重い物の置き場（bulk）

`seed.toml` の `keep` が `research` の時、写真の元（HEIC など）と読みの生の出力を残します（記録の形 §11）。
`bulk` に別の盤の道が在れば、写真の元はそちらに置きます。畑が在るプロジェクトでは `<bulk>/fields/<畑の名>/originals/` です
（`settings.py` の `Settings.records`）。`seed keep` が、今の残す量と、写真の元の置き場と、その空きを出します。

## 秘密

`home.toml`、`~/.config/seed/credentials.toml` は開きません。見てよいのは、在るか、許可（`ls -l`。`home.toml` は 600）だけです。
プロジェクトを動かす時、秘密のファイルは一緒に動きますが、中は読みません。秘密の値が会話や記録に出ていたら、写さず、
本人に、値を取り消して作り直す事を伝えます（`skill-keeper/` 02、09）。

## 一時の物

名が `.` で始まる物（`.unzip-*/`、`.video-*.part`）は、取り込みの途中の物です。終われば消え、落ちた時だけ残ります
（記録の形 §20）。見直しで見つけても、一時間より新しい物は触りません。取り込みの途中かもしれないからです。
