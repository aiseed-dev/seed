# 01 見直す

## この章で読むこと

読むだけで、今の形を確かめる歩。見つけた事の書き方。片付ける時の比べ方。この章の歩は何も変えません。

命令の `--folder <プロジェクト>` は、プロジェクトが `~/seed` なら要りません。道具 `check.py` はこの手引きのフォルダーに在り、
seed を入れた Python で走らせます（`<seed の venv>/bin/python <この手引き>/check.py …`。`--help` で使い方。読むだけで、座標は出さない）。

## 歩

歩 1 プロジェクトと畑を確かめる
- Claude: `seed field list --folder <プロジェクト>`（畑と今の畑）、`cat <プロジェクト>/seed.toml`（`folder`、`keep`、`bulk`、`field`。秘密の欄は無い）
- Claude: `seed project list` は `~/.config/seed/fields.toml` の一覧で、`--folder` に関わらず同じ物を出す。今開いているプロジェクトが
  一覧に在るかだけを見る
- 確かめ: 根に `observations/` が在り、`fields/` も在れば、根の記録は畑に入っていない（03）

歩 2 根と畑の中身を、00 の形と並べる
- Claude: `find <プロジェクト> -maxdepth 3 \( -name observations -o -name photos -o -name skill -o -name originals -o -name videos -o -name notes -o -name '.*' \) -prune -o -print | sort`
- 確かめ: 形の外の物（`uploads/`、写真の入ったフォルダー、ばらばらのメモ）、畑の中の `seed.toml`（在ると、そのフォルダーは
  別のプロジェクトとみなされる。`fields.py` の `split_field`）、畑の中の `skill/` と `CLAUDE.md`
- Claude: `check.py outside <プロジェクト>`。seed から見えない写真・動画・zip を、フォルダーごとに数える

歩 3 どの手引きと CLAUDE.md が使われているか
- Claude: 畑ごとに `seed skill-path --folder <プロジェクト> --field <畑の名>`。根の `skill/` と違う道が出たら、その畑は自分の手引きを使う
- Claude: 使われている手引きと新しい版を `diff -rq` する（04 の歩 2）。違いが本人の節（04 の歩 3）の外に在れば、古い
- Claude: CLAUDE.md は、畑の中の物と根の物、根の物と今の雛形（04 の「CLAUDE.md」）を `diff` する

歩 4 観察が指す写真が在るか
- Claude: 畑ごとに `check.py refs <畑のフォルダー>`
- 確かめ: 無い物は、写真を手で動かしたか消した印。見つけた道を本人に返す

歩 5 写真の元と残す量
- Claude: `seed keep --folder <プロジェクト> --field <畑の名>`（残す量、写真の元の置き場、空き、今の大きさ）
- 読み方: 「全部で」は記録のフォルダーの中だけの大きさで、別の盤の写真の元を含まない。写真の元は、`keep` が `research` の間に
  HEIC などで入れた物にだけ在る。JPEG で入れた写真と、`research` にする前に入れた写真には無い

歩 6 取り込まれていない写真
- Claude: 歩 2 の `outside` で出たフォルダーを、写真の元と畑の写真と比べる:
  `check.py compare --keep <bulk>/fields/<畑の名>/originals --photos <畑のフォルダー> <見つかったフォルダー>`
  （畑が分からない時は、全部の畑の `--keep` と `--photos` を並べる）
- 読み方: 「同じ物が在る」は片付けてよい候補。「JPEG で入っている」は、もう入っている（入れ直すと観察が二つ出来る）。
  「見つからない」は、まだ seed に見えない写真で、02 でどの畑かを確かめて入れる

歩 7 前の置き場の道
- Claude: `grep -rln "<前の置き場>" <プロジェクト>/notes <プロジェクト>/fields/*/notes <手引き>` で、前の道を書いた覚えと手引きを探す
- 確かめ: 道が辿れない覚えは、03 の歩 7 で直すか、覚えの頭に「道は … からの相対」と一行書く。読みの生の出力（`*.raw/`）と
  会話の写しは、その時の記録なので直さない

歩 8 秘密の許可
- Claude: `ls -l <プロジェクト>/home.toml`（在れば `-rw-------`）。中は読まない

## 見つけた事の書き方

一つの見つけた事を一行の表にします。何が起きるかを先に、打つ手を後に。

| 見つけた事 | 何が起きるか | 打つ手 | 誰が |
|---|---|---|---|
| `fields/<名>/skill/` が前の版 | その畑の読みが、新しい章（生物、鳥獣害…）を見ない | 04 で新しくする | Claude（本人の節は写す） |
| 根の `uploads/<日>/` の HEIC 24 枚が、写真の元と同じ | 同じ物が二か所に在り、盤を使う | 消す命令を返す | 本人 |
| `uploads/<別のフォルダー>/` の 17 枚が見つからない | その写真はアプリにも読みにも出ない | 02 でどの畑かを確かめて入れる | 本人に聞いてから Claude |

## 片付ける時

消してよいと言えるのは、別の所に中身が同じ物が在る時だけです。名と大きさでは決めず、`check.py compare` の
「同じ物が在る」で決めます。zip は中の一枚ずつを比べます。結果を本人に見せ、全部が「同じ物が在る」か「JPEG で入っている」
だったフォルダーにだけ、本人が打つ命令（`rm -r <道>`）を返します。一枚でも「見つからない」が在れば、そのフォルダーは残します。
