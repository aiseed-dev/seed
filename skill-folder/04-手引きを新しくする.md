# 04 手引きを新しくする

## この章で読むこと

使われている手引きを見つける。本人の節を見分ける。新しい版に写し、古い版を残す。CLAUDE.md の古さ。

手引き（`skill/`）は `seed init` が一度写した物で、その後は本人の物です。seed の手引きが良くなっても、写しは変わりません
（`cli.py` の `copy_skill` は、在れば触らない）。だから写しは古くなり、新しい章（生物、鳥獣害、加工…）と直した決まりが
読みに効きません。新しくする命令は無いので、この章の歩で写します。

## 歩

歩 1 使われている手引きを見つける
- Claude: 畑ごとに `seed skill-path --folder <プロジェクト> --field <畑の名>`。根の `skill/` か、畑の中の `skill/` か（00「畑の物が勝つ」）

歩 2 新しい版と比べる
- Claude: seed の手引きの置き場は `<seed の venv>/bin/python -c "from seed.cli import package_skill; print(package_skill())"`。
  clone した seed なら、その `skill/` と同じ
- Claude: `diff -rq <使われている手引き> <新しい版>`。違うファイルが、歩 3 の本人の物の外に一つでも在れば、古い版です
  （章の名と数が同じでも、中の決まりが直っている事があります）

歩 3 本人の物を見分ける
- 本人の物は、見出しに「（本人）」が付いた節（その中に Claude が書いた小見出しが在っても、節ごと本人の物として扱う。その畑で
  本人と Claude が話して残した記録だから）、`<!-- 本人が書く -->` の下に書き足された文、`plants/<名>/photos/` の本人の写真と
  その `README.md`、本人が足したファイルです
- clone した seed が在れば、写しの一つ一つが seed の前のどれかの版と同じかを、中身で比べられます。同じ物は本人が触っていません

```bash
blobs=$(mktemp)
git -C <clone した seed> rev-list --all --objects | awk '{print $1}' | sort -u > "$blobs"
cd <使われている手引き>
find . -type f | sort | while read f; do grep -qx "$(git hash-object "$f")" "$blobs" || echo "前のどの版とも違う: $f"; done
rm "$blobs"
```

- 出た物を一つずつ、意味の近い前の版と `diff` して、足された節を書き出します。言い回しの違いだけ（seed の側の直し）なら、本人の物ではありません

歩 4 古い版を残す
- Claude: `mv <使われている手引き> <その畑か根>/notes/skill-<日>-前`（消さない）

歩 5 新しい版を写し、本人の物を入れる
- Claude: `rsync -a --exclude '__pycache__' --exclude '*.py' <新しい版>/ <置く所>/skill/`
- Claude: 歩 3 の本人の節を、新しい版の同じ意味の章の、最後の見出し `## 本人が書く所` のすぐ前に入れます。章の名が変わっていれば、
  意味で合わせます（前の `02-畑を読む.md` は今の `06-畑を読む.md`）。章の中ほどの `<!-- 本人が書く: … -->` の印は、新しい版の物を
  そのまま残します
- 本人の写真と `README.md` は、新しい版の同じ `plants/<名>/photos/` に写し、同じ名の物は本人の物で置き換えます。新しい版の写真は
  座標を外した公開用で、本人の物は座標の入った本人の記録だからです。この写しは公開の物に写しません
- 本人の節の中の言い回しは直しません。見出しも変えません

歩 6 置く所を決める
- 本人の節が一つの畑の事だけなら、その畑の中に `skill/` を置きます（その畑だけがそれを使う）
- 本人の節が無いか、どの畑にも当てはまる事なら、根に一つ置き、畑の中の `skill/` は歩 4 で `notes/` に移します
- 畑の中に置いた手引きは、根の手引きと別に古くなります。次に新しくする時、畑ごとにこの章を繰り返します

歩 7 確かめる
- Claude: `seed skill-path --field <畑の名>` が、思った道を出す
- Claude: `diff -rq <置いた手引き> <新しい版>` で、違うのが本人の節を入れた章と本人の写真と README だけ
- 本人に、入れた本人の節の見出しの一覧を見せる

## CLAUDE.md

`CLAUDE.md` も `seed init` が一度書いた物で、在れば上書きされません。今の雛形は
`<seed の venv>/bin/python -c "from seed.claude_md import text; print(text('ja'))"`（英語は `'en'`）で出ます。

- 根の `CLAUDE.md` と雛形を `diff` し、違いを本人に見せます。本人が書き足した行が無ければ、古い物を `notes/CLAUDE.md-<日>-前` に
  移して雛形を書きます。本人の行が在れば、雛形の新しい行だけを本人の物に足します
- 畑の中の `CLAUDE.md` が根の物と同じなら、畑の物は要りません（`notes/` に移す）。違えば、違う所が本人の行かを見ます
