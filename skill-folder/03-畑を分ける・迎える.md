# 03 畑を分ける・迎える

## この章で読むこと

一つの畑のフォルダーを、畑が幾つも在るプロジェクトにする。外に在る畑のフォルダー（前の置き場、別の PC から持ってきた物）を、
プロジェクトの中の畑として迎える。畑の名。どちらも、観察と写真の相対の道を壊さない事が芯です。

## 畑の名

畑の名はフォルダーの名になり、アプリの上の端に「プロジェクト / 畑」と出ます。画面を録って人に見せる事があるので、
細かい地名を出したくなければ、地名でない名（「北の畑」「自分の畑」）にします。名は本人に聞きます。

## 一つの畑をプロジェクトにする

根に記録が在り、`fields/` がまだ無い時です。

歩 1 二つ目の畑を作る前に、今の記録に名を付ける
- Claude: `seed field new <今の畑の名>`
- 起きる事: 根の記録（observations、photos、originals、videos、place.md、plan.md、next.md、connections.md、public、lots.md、
  ledger.md、weather、procedures、origin、grow。bulk の写真の元も）が `fields/<名>/` へ移り、今の畑になる（`cli.py` の `cmd_field`）
- 確かめ: `seed field list` に `* <名>`。根に `observations/` が無い

歩 2 二つ目の畑を作る
- Claude: `seed field new <二つ目の名>`。今の畑がそれに変わるので、戻すなら `seed field use <名>`

`skill/`、`CLAUDE.md`、`plugins/` は根に残り、どの畑もそれを使います（00）。

## 外のフォルダーを畑として迎える

前に `seed --folder <別の所>` で使っていた畑（中に `seed.toml` と、写した手引きが在る）を、プロジェクトの畑にします。
命令が無いので手で動かします。動かす物は畑のフォルダー丸ごとで、中の写真を一枚ずつ動かす事はしません。

歩 1 迎える前に見る
- Claude: 外のフォルダーの `seed.toml` の `keep`、`bulk`、`[grow]` などを読む（秘密の欄は無い）。プロジェクトの `seed.toml` と違う所を書き出す
- Claude: 外のフォルダーの `skill/` に本人の節が在るか（04 の歩 3）
- Claude: プロジェクトの根に記録が在れば、それが同じ畑の物か（02 の距離）。同じなら、迎えた畑に入れる
- 確かめ: 動かす前の形を本人に見せ、畑の名を聞く

歩 2 動かす
- 人か Claude（本人に一言断ってから）: `mkdir -p <プロジェクト>/fields` → `mv <外のフォルダー> <プロジェクト>/fields/<名>`
- 同じ盤の中なら `mv` は名を変えるだけで、中身は写さない。別の盤なら写してから消すので、終わるまで止めない

歩 3 畑の中の `seed.toml` を外す
- Claude: `mkdir -p fields/<名>/notes && mv fields/<名>/seed.toml fields/<名>/notes/seed.toml-<日>-移す前`
- なぜ: 畑の中に `seed.toml` が在ると、そのフォルダーは別のプロジェクトとみなされる（`fields.py` の `split_field`）
- Claude: 外した物にだけ在った設定（`keep = "research"`、`bulk`、`[grow]`）を、プロジェクトの `seed.toml` に写す。
  `keep` を上げると、プロジェクトの全部の畑で残す量が上がる。下げはしない

歩 4 写真の元を、畑の置き場へ
- `bulk` が在れば、写真の元は `<bulk>/originals/` から `<bulk>/fields/<名>/originals/` へ動かす（00）
- 確かめ: `seed keep` の「重い物は … に置きます」が `<bulk>/fields/<名>` を出し、「写真の元」の大きさが前と同じ

歩 5 根に在った同じ畑の記録を入れる
- 観察（`observations/<日>-<時>.md`）と、その写真の日のフォルダー（`photos/<日>/`）を、迎えた畑の同じ所へ動かす。
  名がぶつかる物は動かさず本人に返す
- 根の `place.md`、`next.md`、`connections.md` は、迎えた畑の物と別の物なので、`fields/<名>/notes/根-<日>/` に動かして残す

歩 6 一覧と今の畑
- Claude: `~/.config/seed/fields.toml` から、迎える前の道の行を外す（道がもう無いので）。`seed field use <名>`
- 確かめ: `seed field list`、`seed skill-path --field <名>`（04）、`seed keep`

歩 7 前の道を書いた所を直す
- 本人のメモ、手引きの資料の道（`skill/plants/*/sources-world.md` の「全文の写しは …」）、動画やスクリプトの道。
  `grep -rn "<前の道>"` で探す。読みの生の出力（`*.raw/`）と会話の写しは、その時の記録なので直さない

迎えた後は、04 で手引きを確かめます。迎えた畑には、前の置き場で写した古い手引きが入っているからです。
