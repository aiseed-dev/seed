# iPhone 版（2026-11-06 夜。作者「flet アプリで専用のカメラを持った方がいいかも」「iphone 版をつくればいい」）

人から届いた写真に座標が入っていなかった。アプリの中で撮り、撮った時の位置を写真に書き込む。

## 入っている物

- 撮る画面（`src/seed/app/capture.py`。設計書 §5.14）: 「話す」の左下の「撮る」で開く。標準のカメラに近い形（作者 11-07「できるだけ標準のカメラアプリに近いものにして」）。画面いっぱいがカメラで、開くとすぐ点く（後ろのカメラ、一番大きい解像度。動画の音は録らない）。
  - 上の端は「← 戻る」と位置の印（誤差の m。押すと取り直す）だけ。録画中は経過の時間も出る。
  - 縦の時は下の帯に、倍率の印、写真と動画の切り替え、最後に撮った物の丸・丸いシャッター・✓（観察にする）。横の時は同じ物を右の端に縦に並べる。
  - 倍率は 1× から。二本の指でつまむか、0.5× 1× 2× 5× 10× のうちその機種で使える印を押す（上の限りは 10×）。
  - 写真は、位置が取れるまでシャッターが切れない。一度に 6 枚まで。✓ で観察にする。
  - 動画は、位置が無くても録れる。止めると記録の `videos/<日>/` に置き、撮った時と所を同じ名の `.json` に書く（記録の形 §20）。
  - 最後に撮った物の丸を押すと見返しになり（前後に送れる）、「消す」で消える。下の帯の「元に戻す」で戻る。カメラを出る時に本当に消える。
  - 「← 戻る」と端末の戻る操作で話すへ戻る（アプリは閉じない）。写真があれば、観察にするかを聞く。家のサーバー（`seed home`）に繋いでいれば、出た時にまだ送っていない動画を PC へ送る（消した物は送らない。設計書 §5.13）。
- 撮った写真に座標・時刻・向き・誤差を書く（`photos.stamp`）。後はスマートフォンのカメラの写真と同じ道。
- 撮った写真と動画の写しを共有の写真の置き場に残すのは、今は Android だけ（`Pictures/seed/<日>/`）。iPhone の写真ライブラリーに入れるには別の部品が要る。
- 上の端の歯車で設定のフォーム（PC を探す、サーバーの URL、6 桁の招待コード、読む所、自分の鍵。設計書 §5.13）。
- 読み取りと話す（言葉で頼む細かい作業）は、本人の Claude の鍵でスマートフォンから直に、か seed のサーバー経由（家の PC の `seed home`、または招待コードで入るサーバー。`src/seed/direct.py`）。どちらも無ければ、本人の言葉として書き留める。
- スマートフォンの幅に合わせる。
- 入口 `src/main.py`、設定は `pyproject.toml` の `[tool.flet]`。カメラと位置の許しの文は `[tool.flet.ios.info]`（音を録らないので、マイクの許しは入れていない）。

## Mac でビルドする

要る物: macOS、Xcode 15 以降、CocoaPods 1.16 以降、Apple Developer Program の加入。

```bash
git clone https://github.com/aiseed-dev/seed.git && cd seed
```

```bash
python3 -m venv .venv && .venv/bin/pip install "flet[all]==1.1.0"
```

シミュレーターで開く（署名は要らない。カメラは動かない）:

```bash
.venv/bin/flet build ios-simulator
```

実機に入れる（署名が要る。Team ID は Apple Developer の Membership の頁）:

```bash
.venv/bin/flet build ipa --ios-team-id <Team ID> --ios-export-method debugging
```

## 確かめた事

- スマートフォンに入れる依存だけ（flet、flet-camera、flet-geolocator、pillow、httpx、pyyaml）の環境で、アプリが読み込め、観察の画面（11-06 夜の時点。今の「話す」）まで作れる。
- ブラウザをスマートフォンの幅にして、撮る釦、撮る画面、位置を許さなかった時の文が出る。
- 撮った写真に書いた座標・時刻・向きが、読む側で同じ値に戻る（テスト）。
- Android の実機（11-07、`flet debug android` で USB で繋いだ実機に入れた）で、同じ撮る画面の部品（flet-camera、flet-geolocator）が動き、アプリで撮った写真（元の大きさ、座標入り）が `seed home` で PC のプロジェクトフォルダーに届き、観察として読まれた。今の撮る画面は、その実機で作者が使って言った事（倍率が変えられない、動画が撮れない、横にした時に文字が邪魔、消しにくい）から組み直した物。

## 確かめていない事

- Mac でのビルド、iPhone の実機、iPhone でのカメラと位置の実際の動き。
- 組み直した撮る画面（11-07 夕）を、実機で縦と横にして使う所。動画が PC に届く所。
- スマートフォンのアプリには手引き（skill）が入らない（自分の鍵で呼ぶ時は組み込みの短い決まりで動く。サーバー経由ならサーバーの手引き）。
- スマートフォンの安全な置き場の部品（`flet-secure-storage`）がスマートフォンのビルドで使えるか。本人の Claude の鍵は今、PC と同じ `~/.config/seed/credentials.toml`（600。スマートフォンではアプリの入れ物の中）に置く。
